# Asset Images – Cara Pakai

Letakkan file gambar dengan nama tepat di bawah ini di folder `assets/`:

| Nama File                  | Kegunaan                                      | Ukuran saran     |
|----------------------------|-----------------------------------------------|------------------|
| `bedroom_sleep.png`        | Kamar tidur + cewek tidur + pocong di luar jendela | 1280×720 atau 16:9 |
| `bedroom_pocong_in.png`    | Kamar yang sama, pocong berdiri di belakang lampu tidur | sama |
| `classroom_wake.png`       | Cewek terbangun di kelas (pose mirip gambar 3) | 1280×720 |
| `dream_photo.png`          | Komposit foto mimpi: kamar + pocong tidur selimutan | 800×600 |

Setelah file ditaruh, refresh browser. Kode sudah otomatis memakai gambar jika ada, fallback ke CSS/emoji jika tidak ada.
